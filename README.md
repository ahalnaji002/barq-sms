# Barq SMS

## Project Overview

تطبيق Flutter لأجهزة Android لإدارة كشوف المستفيدين، استيراد بياناتهم من
Excel، إرسال رسائل SMS مخصصة، والاحتفاظ بسجل محلي لعمليات الإرسال.

## Features

- استيراد ملفات `.xlsx` مع اكتشاف ورقة البيانات وترتيب الأعمدة تلقائيًا؛ يكفي
  وجود رقم الجوال واسم أو اسم الطالب أو ولي الأمر، ورقم الهوية اختياري.
- إدارة كشوف المستفيدين ومنع تكرار رقم الهوية (عند توفره) أو الجوال داخل الكشف.
- عرض العدد الإجمالي للمستفيدين بدون تكرار اعتمادًا على الهوية، أو الجوال عند غيابها.
- تخصيص الرسائل بمتغيرات الاسم ورقم الهوية واسم الطالب واسم ولي الأمر؛ تُقرأ
  بيانات الطالب وولي الأمر اختياريًا من أعمدة Excel المطابقة.
- متابعة الإرسال الجماعي بعدّاد وشريط تقدم يوضح عدد الرسائل التي تمت معالجتها.
- سجل محلي لنتائج الإرسال.
- حالات إرسال موثوقة من Android: قيد الإرسال، أُرسلت من الجهاز، تم التسليم
  (عندما توفر الشبكة تقرير التسليم)، أو فشلت مع سبب مفهوم.
- واجهة عربية RTL مع وضع فاتح وداكن.
- عرض رقم إصدار التطبيق تلقائيًا في شاشة الترحيب.
- تشفير قاعدة البيانات كاملة باستخدام SQLCipher.
- حفظ مفتاح التشفير في التخزين الآمن للنظام بدل ملفات التطبيق العادية.
- ترحيل قواعد البيانات القديمة غير المشفرة تلقائيًا مع التحقق من الجداول
  وعدد السجلات قبل استبدال الملف الأصلي.
- إعادة بناء جدول المستفيدين القديم تلقائيًا بقيود `NOT NULL` وعلاقة حذف
  صحيحة مع الكشوف، مع مقارنة عدد السجلات وفحص العلاقات قبل اعتماد الترقية.
- تعطيل النسخ الاحتياطي السحابي ونقل بيانات التطبيق لحماية قاعدة البيانات
  ومفتاحها من الانفصال أو النسخ غير المقصود.
- قفل اختياري للتطبيق برمز PIN من 4 إلى 8 أرقام، مع قفل تلقائي عند
  مغادرة التطبيق. لا يتم حفظ الرمز نفسه؛ تُحفظ بصمته داخل التخزين الآمن.
- حذف نهائي لجميع الكشوف والمستفيدين وسجل الرسائل من شاشة الإعدادات، مع
  طلب رمز PIN عند تفعيل القفل.
- منع لقطات الشاشة وإخفاء محتوى التطبيق من معاينة التطبيقات الحديثة على
  Android لحماية الأسماء والهويات الظاهرة على الشاشة.

## Setup

1. ثبّت Flutter المتوافق مع Dart `3.5.3` أو أحدث.
2. شغّل `flutter pub get`.
3. شغّل التطبيق على جهاز Android باستخدام `flutter run`.

يتطلب بناء Android حاليًا `compileSdk 36`. عند تشغيل نسخة محدثة فوق نسخة
قديمة، يتم تشفير قاعدة البيانات الحالية عند أول فتح. لا تحذف بيانات التطبيق
أثناء هذه العملية، لأن مفتاح التشفير محفوظ داخل Android Keystore.

للتحقق من المشروع:

```text
flutter analyze
flutter test
flutter build apk --debug
```

### إصدار Android الرسمي

إصدار الإنتاج الحالي هو `1.1.5+8` ويستخدم معرّف التطبيق الثابت
`com.barqsms.barq_sms`. تتطلب أوامر Release الملف المحلي
`android/key.properties` ومفتاح التوقيع المشار إليه داخله.

```text
flutter build apk --release --split-per-abi
flutter build appbundle --release
```

ملفات التوقيع وكلمات المرور مستبعدة من Git. يجب حفظ نسخة احتياطية آمنة من:

- `android/keystore/barq-sms-upload.jks`
- `android/release-signing-credentials.txt`

فقدان المفتاح أو كلمة مروره يعني عدم القدرة على إصدار تحديثات موقعة للتطبيق.

## Dependencies

- `provider`: إدارة الحالة.
- `file_picker` و`excel`: اختيار ملفات Excel وقراءتها.
- `sqflite_sqlcipher`: تخزين SQLite مشفر باستخدام SQLCipher.
- `flutter_secure_storage`: حفظ مفتاح قاعدة البيانات عبر التخزين الآمن للنظام.
- `package_info_plus`: قراءة رقم إصدار التطبيق لعرضه تلقائيًا في شاشة الترحيب.
- `crypto`: إنشاء بصمة آمنة لرمز PIN بدل تخزين الرمز نفسه.
- `shared_preferences`: الإعدادات غير الحساسة مثل المظهر ونص الرسالة الافتراضي.
- `another_telephony`: طلب صلاحيات الرسائل وإرسال SMS على Android.
